# Salamander Grand Piano V3

Recordings by **Alexander Holm**, licensed under [Creative Commons Attribution 3.0 Unported](https://creativecommons.org/licenses/by/3.0/). Copyright remains with the author. No endorsement is implied.

Source instrument: https://sfzinstruments.github.io/pianos/salamander/
Original archive: https://archive.org/details/SalamanderGrandPianoV3

These are stereo Ogg Vorbis conversions distributed by Jan Forst (darosh) at https://github.com/darosh/samples-piano, from the `@audio-samples/piano-velocity1` through `piano-velocity16` packages, version 1.0.5. Keys bundles all 480 attack recordings unchanged from those packages. The originals were converted to Ogg upstream; Keys applies pitch transposition, gain and damper envelopes during playback. Release-noise, pedal-noise and resonance samples are not included.

The instrument is a Yamaha C5, sampled every minor third from A0 to C8 at 16 velocity levels. Intervening keys are transposed by at most one semitone.

`provenance.json` records the package URLs, file sizes and SHA-256 digests. Run `python scripts/fetch-piano.py` from the project root to reproduce the bundled files; this downloads data only and does not install or execute package code.
